Team project · Machine Learning + Web App

RentIQ House Rent Prediction

A full-stack web app that places a rental listing in a monthly-rent bracket. A trained machine-learning model sits behind a Flask API, and a web frontend lets users enter property details and view the prediction.

PythonFlaskFlask-CORSscikit-learnRandom ForestStandardScalerpandasNumPyjoblibHTML / CSS / JavaScript

How it works

Web frontend→Flask API /predict→Scaler + Random Forest→Category, range, confidence

Inputs used by the model

City (Bangalore, Chennai, Delhi, Hyderabad, Kolkata, Mumbai), BHK, size in sq ft, floor, area type, furnishing status, preferred tenant, and bathrooms.

Key features

  • Classifies rent as Low, Medium or High: below ₹10,000, ₹10,000–₹30,000, or above ₹30,000 per month
  • API returns a confidence percentage with each prediction
  • Recent predictions and summary stats through /history and /stats
  • Saved model, scaler and feature list loaded at startup

My contribution

Group project. I collaborated with the team on the frontend and backend structure and the prediction workflow that uses the saved model and preprocessing files. I did not build the whole project alone.
